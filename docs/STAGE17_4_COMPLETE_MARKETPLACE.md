# Stage 17.4 — Complete Marketplace UX/UI Prototype

Stage 17.4 реализует отдельный интерактивный frontend-прототип по маршруту
`/marketplace`. Он не меняет NestJS API, Prisma, production-данные или
инварианты Stages 1–15. `/premium` сохранён как регрессионный маршрут Stage
17.1–17.3.

## Реализованные поверхности

- рекомендательная главная с синтетическими промоблоками, локальными
  рекомендациями и автоматической порционной лентой;
- каталог товаров и отдельный каталог услуг, поиск, категории, фильтры и
  сортировка;
- товар, варианты и несколько предложений продавцов;
- публичная страница магазина, рейтинг, отзывы и ассортимент;
- корзина по продавцам, количества, самовывоз/демо-доставка и локальная история
  заказов;
- шесть специализированных мастеров услуг с параметрами, файлами, сроком,
  исполнителем, валидацией и предварительной стоимостью;
- кабинет покупателя и кабинет продавца;
- локальное добавление товара продавцом, изображение, цена и остаток;
- History API, Back/Forward, восстановление прокрутки и мобильная навигация;
- RU/UZ/EN без изменения состояния корзины и заказа.

Каталог, checkout, расчёты, файлы, отзывы и заказы — исключительно локальные
синтетические данные. Это не production marketplace и не окончательная схема
БД. Точка будущего подключения к API изолирована представлением и типизированной
frontend-моделью; production-интеграция требует отдельного согласования.

## Безопасность автономного прототипа

Windows-сервер слушает только loopback `127.0.0.1`, выбирает первый свободный
порт 4173–4183, запрещает сетевые подключения CSP `connect-src 'none'`, отдаёт
`Cache-Control: no-store, private` и SPA fallback для всех маршрутов.

## Verification

`ops/verify/stage17-4.sh` выполняет unit, lint, typecheck, production build,
полный Playwright regression preview-приложения без retries, отдельный Stage
17.4 E2E, desktop/mobile screenshots и создаёт checksummed Windows ZIP. Итог
сохраняется в машинно-читаемом
`stage17-4-complete-marketplace-verification-report.json` даже при ошибке.
