AGAT PRINT — Stage 16.1 Visual Preview
======================================

1. Распакуйте ZIP полностью в отдельную папку.
2. Дважды щёлкните Start-AGAT-Web-Preview.cmd.
3. Браузер откроет http://127.0.0.1:4173 автоматически.
4. Проверьте интерфейсы «Клиентский Web», «Мобильное приложение» и
   «Программа студии», а также языки UZ / RU / EN.
5. Для остановки вернитесь в окно запуска и нажмите Ctrl+C.

Приложение не устанавливается и не требует Docker. Оно работает только на
локальном адресе, использует синтетические данные и не отправляет запросы к
production API. Не вводите личные данные и не выбирайте реальные документы.
Скрипт запуска применяет ExecutionPolicy только к своему процессу PowerShell;
он не меняет системную политику, реестр или настройки безопасности Windows.

Если порт 4173 занят, закройте другую локальную программу, использующую этот
порт, и повторите запуск. Windows PowerShell 5.1 входит в Windows 10/11.
