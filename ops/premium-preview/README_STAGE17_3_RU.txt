AGAT PRINT — утверждённый дизайн Stage 17.3

ЗАПУСК НА WINDOWS 10/11

1. Распакуйте ZIP полностью в обычную папку.
2. Дважды щёлкните Start-AGAT-Approved-Design.cmd.
3. Браузер автоматически откроет локальный интерфейс AGAT PRINT.
4. Для остановки закройте окно сервера или нажмите Ctrl+C.

Docker, Node.js и программирование не нужны. Конфигурацию редактировать не
нужно. Если порт 4173 занят, запуск автоматически выберет свободный локальный
порт до 4183 и покажет итоговый адрес.

Сервер слушает только 127.0.0.1 и недоступен другим устройствам в сети.
Используются только синтетические демонстрационные данные и оригинальные
локальные изображения. Реальные заказы, загрузки, платежи и доставка не
выполняются; backend AGAT PRINT не вызывается.

ЧТО ПРОВЕРИТЬ

- соответствие утверждённой композиции: шапка, каталог слева, баннер,
  преимущества, услуги, промоблоки и товарные карточки;
- переключение RU / UZ / EN;
- поиск, категории, избранное и карточки товаров;
- добавление, изменение количества и удаление товаров в корзине;
- отдельные пошаговые мастера шести услуг;
- адаптивность при изменении ширины окна;
- подгрузку новых уникальных товаров при прокрутке вниз.
