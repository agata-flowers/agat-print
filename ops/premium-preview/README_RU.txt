AGAT PRINT Premium — интерактивный прототип

1. Распакуйте ZIP полностью в обычную папку.
2. Дважды щёлкните Start-AGAT-Premium-Prototype.cmd.
3. Браузер откроет http://127.0.0.1:4173/premium?lang=ru.
4. Для остановки закройте окно или нажмите Ctrl+C.

Docker, Node.js и программирование не нужны. Windows может показать стандартное
предупреждение о локальном CMD-файле — файл запускает только локальный сервер на
127.0.0.1 и не принимает соединения из сети.

Это синтетический UX/UI-прототип. Реальные заказы, платежи и доставка не выполняются.
